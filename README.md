# Maracuya — AI Chat UI/UX

A complete UI/UX exploration for an AI chat product focused on conversations, files, and AI-powered workflows.

## Overview

This project explores the UX architecture of an AI chat platform rather than focusing only on the visual interface.

The goal was to create a scalable experience for users who need to communicate with AI while working with information and files.

## UX Focus

The design focuses on reducing cognitive load and making AI interactions feel predictable and controllable.

Key principles:

- Clear hierarchy
- Progressive disclosure
- Contextual actions
- User control
- Consistent feedback
- Reusable patterns
